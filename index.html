About the Project

This project uses Machine Learning to recommend personalized treatment plans based on patient data. It analyzes symptoms, age, medical history, and predicts the best treatment approach.

How It Works

  • Preprocessing & Cleaning
  • ML Model Training (e.g., Decision Tree / Random Forest)
  • Prediction of Treatment Plan
