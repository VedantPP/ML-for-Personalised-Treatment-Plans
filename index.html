About Project

This project uses Machine Learning algorithms to recommend personalized treatment plans using patient health data. The system analyzes symptoms, age, blood pressure, sugar level, cholesterol, BMI, and heart rate to provide smart healthcare predictions.

Key Features

AI Prediction

Predicts treatment recommendations using ML algorithms.

Health Analysis

Analyzes patient parameters for risk detection.

Fast Results

Provides instant predictions and suggestions.

Modern Dashboard

Interactive and attractive healthcare interface.

How It Works

  • ✔ Data Collection from Patient Records
  • ✔ Data Cleaning & Preprocessing
  • ✔ Model Training using Random Forest / Decision Tree
  • ✔ Prediction & Personalized Treatment Recommendation
